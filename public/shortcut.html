One-time setup · about 5–10 minutes

Sync from iPhone without an export app

Build the free VitaIQ Sync shortcut once. After that, tap Sync from iPhone on VitaIQ's front page (or run the shortcut), type how many days, and your dashboard updates in a few seconds.

🔒 Private: the shortcut reads Apple Health on your iPhone and opens VitaIQ with the data after a # in the link. Browsers never send that part to any server — the data is processed in Safari on your phone, same as a ZIP upload.

The whole shortcut at a glance — no loops, no settings to hunt for:

  1. Ask for Input — how many days
  2. One Find Health Samples per metric, with a Nothing between them
  3. One Text that lists them all
  4. Make Archive → Base64 Encode → URL Encode → Open URLs

1 · Start the shortcut

  1. Open the Shortcuts app → tap +. Tap the name at the top → Rename → type exactly VitaIQ Sync.
  2. Add Ask for Input: Input Type Number, prompt How many days?.

2 · Find each metric (2 actions each)

Add Find Health Samples and set it up once:

  • Type: Heart Rate Variability
  • Add Filter: Start Date · is in the last · tap the number → Provided Input · days
  • Group By: Day · Sort by Start Date · Order Oldest First · Limit off

Then for each next metric: add a Nothing action, then long-press the first Find → Duplicate, drag the copy below the Nothing and change only its Type. The Nothing matters: without it Shortcuts turns the next Find into a Filter of the previous one and it finds nothing.

  2. Make Archive from the Text · Format gzip · Name vitaiq
  3. Base64 Encode the Archive · Line Breaks None
  4. URL Encode the Base64 Encoded result
  5. Open URLs: type https://vitalstats.netlify.app/#sync= and right after it insert URL Encoded Text (no space).

Compression keeps the link small. If Make Archive gives you trouble, skip the Make Archive and Base64 steps and URL-encode the Text directly — VitaIQ reads both.

About sessions: Shortcuts can't read workouts, but during a recorded workout your Apple Watch measures heart rate every few seconds. VitaIQ finds those stretches and shows each one under Effort → Sessions with its heart-rate curve, average/max and time in zones — tap one to tag it (e.g. Tennis). The share card counts them as Workout days; with none found it shows Active days (30+ exercise minutes).

Already built the older version (with Repeat loops or Share Sheet input)? It still works — no need to rebuild.

4 · First run

  • Run it from the Shortcuts app and enter 7. iOS asks to allow Health access for each type — tap Allow.
  • When asked whether the shortcut may open vitalstats.netlify.app, choose Always Allow.
  • Safari opens VitaIQ and shows “Synced … from iPhone” with what arrived (e.g. HRV 7 days · Sleep 7 nights · Steps 7 days). If something's missing or you see an error, send a screenshot to Wai Git's Engineer.

Using it

  • From VitaIQ: tap Sync from iPhone on the front page (or at the top of the Today tab), then type the number of days when the shortcut asks (7 quick · 30 recommended · 90–180 longer history).
  • From anywhere: run VitaIQ Sync (Home Screen icon, widget, Siri, or Apple Watch) and type the number of days.
  • Every sync is added to the history saved in Safari, so after one longer sync, a quick 7- or 30-day sync keeps trends up to date. 30 days keeps your baselines most accurate.
  • The CSV ZIP upload still works as before.

Home Screen VitaIQ icon? On iPhone, a website added to the Home Screen keeps its own separate storage from Safari. The shortcut always opens Safari, so synced data lands in Safari's VitaIQ. Use VitaIQ in Safari for synced data (you can add the VitaIQ Sync shortcut itself to the Home Screen instead).

Health app limits: iOS keeps Health data locked while the iPhone is locked, so run the sync with the phone unlocked. Blood-oxygen dips are based on daily averages when synced this way.
