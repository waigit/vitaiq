One-time setup · about 15 minutes

Sync from iPhone without an export app

You build a small Apple Shortcut called VitaIQ Sync once. After that, tap Sync in VitaIQ (or run the shortcut), pick a period, and your dashboard updates in a few seconds.

🔒 Private: the shortcut reads Apple Health on your iPhone and opens VitaIQ with the data after a # in the link. Browsers never send that part to any server — the data is processed in Safari on your phone, same as a ZIP upload.

1 · Create the shortcut

  1. Open the Shortcuts app → tap +.
  2. Tap the name at the top → Rename → type exactly VitaIQ Sync.
  3. This one is a setting, not an action (don't search for it): tap the small ⌄ next to the shortcut name at the top → Details (called Settings on some iOS versions) → turn on Show in Share Sheet → Done. A block Receive Any input from Share Sheet appears at the top.
  4. In that block, tap Continue (next to “If there's no input”) → choose Ask For → Number, and set the prompt to How many days?. This is how you pick the period when you run the shortcut yourself; VitaIQ's Sync button fills it in for you.
  5. Add Set Variable: name Days, value Shortcut Input.

2 · Add one block per metric

Each block is 4 actions. Build the first one, then long-press each action → Duplicate to make the next block and just change the Type.

  1. Find Health Samples where Type is Heart Rate Variability
    → Add Filter: Start Date · is in the last · Days (the variable) · days
    → Group By: Day · Sort by Start Date · Order Oldest First · Limit off
  2. Repeat with Each item in Health Samples
  3. Inside the repeat: Text containing
    Repeat Item → tap it → Start Date → Date Format ISO 8601 (turn on Include ISO 8601 Time)
    then type |
    then Repeat Item → Value
  4. End Repeat (added automatically)

The Text inside should read like: Start Date|Value

Make one block for each of these:

Sleep is slightly different (it has a start, an end and a stage):

  1. Find Health Samples where Type is Sleep, Start Date is in the last Days days, sorted by Start Date, Oldest First, no grouping.
  2. Repeat with Each → Text: Start Date (ISO 8601)|End Date (ISO 8601)|Value → End Repeat

3 · Put it together and open VitaIQ

  1. Add a Text action after the last block. Type the lines below; where it says [Repeat Results], tap Select Variable and tap the End Repeat of that metric's block: 
    VITAIQ1
#Heart Rate Variability
[Repeat Results]
#Resting Heart Rate
[Repeat Results]
#Blood Oxygen
[Repeat Results]
#Steps
[Repeat Results]
#Active Energy
[Repeat Results]
#Resting Energy
[Repeat Results]
#Exercise Minutes
[Repeat Results]
#Sleep
[Repeat Results]
    (add #Cardio Fitness / #Respiratory Rate sections too if you made those blocks)
  2. Make Archive from the Text · Format gzip · Name vitaiq
  3. Base64 Encode the Archive · Line Breaks None
  4. URL Encode the Base64 Encoded result
  5. Open URLs: type https://vitalstats.netlify.app/#sync= and right after it insert URL Encoded Text (no space).

Compression keeps the link small. If Make Archive gives you trouble, you can skip steps 2–3 and URL-encode the Text directly — VitaIQ reads both.

4 · First run

  • Run it from the Shortcuts app and enter 7. iOS asks to allow Health access for each type — tap Allow.
  • When asked whether the shortcut may open vitalstats.netlify.app, choose Always Allow.
  • Safari opens VitaIQ and shows “Synced … from iPhone” with what arrived (e.g. HRV 7 days · Sleep 7 nights · Steps 7 days). If something's missing or you see an error, send a screenshot to Wai Git's Engineer.

Using it

  • From VitaIQ: on the Today tab, pick 7 days / 30 days / 3 / 6 months under Sync from iPhone and tap Sync.
  • From anywhere: run VitaIQ Sync (Home Screen icon, widget, Siri, or Apple Watch) and type the number of days.
  • Every sync is added to the history saved in Safari, so after one longer sync, a quick 7- or 30-day sync keeps trends up to date. 30 days keeps your baselines most accurate.
  • The CSV ZIP upload still works as before (and is the only way to bring in workout types for now).

Home Screen VitaIQ icon? On iPhone, a website added to the Home Screen keeps its own separate storage from Safari. The shortcut always opens Safari, so synced data lands in Safari's VitaIQ. Use VitaIQ in Safari for synced data (you can add the VitaIQ Sync shortcut itself to the Home Screen instead).

Health app limits: iOS keeps Health data locked while the iPhone is locked, so run the sync with the phone unlocked. Blood-oxygen dips are based on daily averages when synced this way.
